DistSys diagram demo

One service, one hub, one event: mermaid.run() calls bindFunctions automatically once each SVG below is inserted, so the orbs start streaming with no extra wiring.

Basic stream (service → hub)

distsys-beta
service:
  id: orders
  label: Order Service
hub:
  id: bus
  label: Event Hub
event:
  id: order-created
  label: OrderCreated
  interval: 300
  from: orders
  to: bus

Reversed direction (hub → service)

event.from/event.to pick the direction: swapping them flips which way the orbs travel, arrowhead and all. 

distsys-beta
service:
  id: orders
  label: Order Service
hub:
  id: bus
  label: Event Hub
event:
  id: order-confirmed
  label: OrderConfirmed
  interval: 600
  from: bus
  to: orders

Controlling the stream from the page

mermaidAPI.render() returns bindFunctions; calling it on the live SVG attaches a .distSys controller with play(), pause(), stop(), and setPathVisible() / togglePath() for the connecting line.
