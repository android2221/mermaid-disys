DistSys diagram demo

Services, a hub, and a list of events: mermaid.run() calls bindFunctions automatically once each SVG below is inserted, so every event's orbs start streaming with no extra wiring.

Basic stream (service → hub)

distsys-beta
services:
  - id: orders
    label: Order Service
hub:
  id: bus
  label: Event Hub
events:
  - id: order-created
    label: OrderCreated
    interval: 300
    routes:
      - from: orders
        to: bus

One event, two routes: service → hub, then hub → service

An event is declared once — a stable id, label, interval, and (optionally) color — and carries a routes list underneath. Two routes between the same service and hub, going opposite directions, render as two parallel lines instead of overlapping, each animating independently. Each route can override the shared label with its own. 

distsys-beta
services:
  - id: orders
    label: Order Service
hub:
  id: bus
  label: Event Hub
events:
  - id: order-lifecycle
    label: OrderLifecycle
    interval: 500
    routes:
      - from: orders
        to: bus
        label: OrderCreated
      - from: bus
        to: orders
        label: OrderConfirmed

Color-coded events

event.color accepts a hex code or a CSS color name, recoloring that event's line(s) and orb(s) — useful for telling several event types apart at a glance. The arrowhead stays neutral (SVG markers don't inherit color from the path referencing them). 

distsys-beta
services:
  - id: orders
    label: Order Service
  - id: payments
    label: Payment Service
hub:
  id: bus
  label: Event Hub
events:
  - id: order-created
    label: OrderCreated
    interval: 500
    color: "#3b82f6"
    routes:
      - from: orders
        to: bus
  - id: payment-captured
    label: PaymentCaptured
    interval: 700
    color: mediumseagreen
    routes:
      - from: payments
        to: bus

Multiple services, direct service → service line

A route's from/to also work between two services directly, bypassing the hub entirely — the hub still renders (spanning both services) but this particular route's line runs straight across. 

distsys-beta
services:
  - id: orders
    label: Order Service
  - id: payments
    label: Payment Service
hub:
  id: bus
  label: Event Hub
events:
  - id: payment-requested
    label: PaymentRequested
    interval: 500
    routes:
      - from: orders
        to: payments

Controlling the stream from the page

mermaidAPI.render() returns bindFunctions; calling it on the live SVG attaches a .distSys controller with play(), pause(), stop(), and setPathVisible() / togglePath() for the connecting line(s). With multiple routes, these apply to all of them at once; svgEl.distSys.events['stock-reserved[0]'] reaches a single route (keyed as eventId[routeIndex]).
